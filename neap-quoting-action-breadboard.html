How work moves

A booking can become an RFQ. An RFQ then sits in one lane at a time. These are the only moves.

Other exits (any time)

Cancel a booking Leaves from Shipper bookings. Never becomes an RFQ.
Skip Draft Convert can land straight in Submitted.
Delete a Draft Leaves the board. Nothing is quoted.
Cancel a rejected or expired RFQ Leaves the board. No loop back.

Card click: bookings go to the existing Bookings page. Every RFQ lane goes to the existing Review Quotes page.

The page, top to bottom

Same screen all day. These regions always sit in this order. Summary is the daily starting point.

SidebarApp nav. Can fold to icons so the board gets width.
HeaderPod picker. Switching pod rescopes the board, assignees, and target.
Count pillsHow many active RFQs, expired, rejected, new clients. Tapping a pill can clear filters.
Target vs achievedThis month’s bar. Achieved = first quote accept, not bookings. Upload projections. History of uploads.
Summary stripAlways show the pulse line and last refreshed (PT). Do next (top 3), See all, and Astra can fold away together. Pulse does not fold. Astra does not reorder Do next. See all and Astra never both open.
FiltersNarrow the same board. Do not take the AM to another page.
BoardMain lanes (bookings → accepted) and User actionables (draft, expired). Each group can fold to a rail.

Summary strip

PulseOne line: new RFQs and new bookings since yesterday (PT). Pending to quote = Submitted only, and how many of those already waited a day. New rejections. Cleanup only if too many CRD-stale cards. Never a Do next row.
Do nextThree rows, in this order: Quote now (Submitted waiting) → Convert now (booking waiting) → Send booking → Follow up → Reissue → Win back. Row focuses that card.
See allOpens the full ranked list. Closes Astra. Pick a row → the card.
AstraOpens chat about this board. Closes See all. Does not move cards or change the list.
